# Evolución de los Modelos
## ¿Qué es un modelo de lenguaje?
Es un sistema de IA que aprende patrones del lenguaje a partir de datos de entrenamiento. Su función puede consistir en predecir la siguiente palabra, completar textos y generar respuestas a partir de una entrada, llevandolo acabo mediante redes neuronales.

Este modelo empezo a ser grande, ya que entreno con grandes cantidades de informacion o datos. Los datos contienen parametros y esos parametros son valores que se ajustan dura realizar tareas, resumir documentos, traducir textos, responder preguntas y generar código.

## ¿Qué son los modelos con razonamiento explícito?
razonamiento explicito se refiere a que el modelo utiliza procesos intermedios para llegar a una respuesta. Como modelo es entrenado para resolver problemas que requieren varios pasos antes de producir una respuesta. En lugar de responder inmediatamente, pueden dedicar procesamiento adicional a analizar un problema, explorar posibles soluciones y revisar sus resultados. Ejemplo: resolver problemas de matemáticas, programación y lógicos.

Para aumentar el tamaño de un modelo intervienen las técnicas de entrenamiento y los recursos de cómputo empleados cuando el modelo responde.

Entrenamiento especializado: se utilizan métodos como el aprendizaje por refuerzo y el ajuste posterior al entrenamiento para mejorar la resolución de problemas de varios pasos.

Cómputo durante la inferencia:cuando recibe una consulta, el modelo puede utilizar procesamiento adicional para evaluar alternativas y elaborar una respuesta.

Tiempo y recursos disponibles:permitir más procesamiento puede mejorar los resultados en determinadas tareas, aunque también puede aumentar el tiempo de respuesta y el consumo de recursos.

Por lo tanto, no basta con hacer un modelo más grande para garantizar mejores capacidades de razonamiento. Es necesario considerar cómo fue entrenado y cuánto procesamiento puede utilizar al responder.
