# Casos de uso de MCP

## Herramientas que utilizan MCP

Actualmente existen diferentes plataformas de desarrollo que integran MCP para conectar sus agentes de inteligencia artificial con herramientas y servicios externos. Algunos ejemplos son:

### 1. Google Antigravity

Es un entorno de desarrollo que utiliza agentes de inteligencia artificial para analizar, crear y modificar código. Tiene compatibilidad con MCP, lo que permite conectar servidores externos para consultar información y ejecutar herramientas.

### 2. Cursor

Es un editor de código con un agente de IA que puede explorar un proyecto, buscar archivos, modificar varios archivos y ejecutar comandos. Mediante MCP puede conectarse con servicios externos, como bases de datos, GitHub y otras herramientas.

### 3. Claude Code

Es un agente de programación de Anthropic que trabaja desde la terminal y entornos de desarrollo compatibles. Puede analizar repositorios, modificar archivos, ejecutar pruebas y utilizar servidores MCP para conectarse con herramientas externas.

## ¿Cómo editan repositorios completos sin subir archivos manualmente?

Estas plataformas pueden trabajar directamente con un repositorio local. El usuario abre la carpeta del proyecto y el agente puede:

1. Analizar la estructura del repositorio y localizar sus archivos.
2. Leer el código para comprender cómo está organizado el proyecto.
3. Identificar los archivos que necesitan modificaciones.
4. Editar varios archivos de acuerdo con la tarea solicitada.
5. Ejecutar comandos y pruebas para comprobar los cambios.

De esta manera, no es necesario subir cada archivo manualmente a una conversación. El agente trabaja sobre el proyecto abierto y utiliza sus herramientas para acceder a los archivos.

MCP complementa este funcionamiento al permitir conectar servicios externos, como GitHub, bases de datos y sistemas de documentación.


Qwen: es una familia de modelos de inteligencia artificial desarrollada por Alibaba. No es una plataforma de desarrollo, aunque sus modelos pueden utilizarse dentro de herramientas compatibles con MCP.

Google Antigravity: sí es un entorno de desarrollo (IDE) que integra agentes de inteligencia artificial y permite conectarse con servidores MCP.
